# Web framework benchmark contract

Contract version 4 separates precomputed static throughput from request-time dynamic SSR and adds repeated stream distributions. Every run creates high-entropy product IDs that are unknown to the fixture and uses them for both validation and the measured dynamic URL. Each response must contain its requested ID and remain distinct, so a finite table of bodies prepared before the run cannot satisfy the contract.

The scored stream scenario has one 20ms deferred dependency, one 80-item payload, and one shell-to-done boundary for every framework. The runner records every downstream chunk arrival timestamp and rejects any sample unless the shell and `data-stream="done"` payload arrive in distinct chunks at least 10ms apart. Full runs use 5 warmups and 20 measured samples per framework. Tachyon's separate `/stream-evidence` route preserves multi-chunk completion, cancellation, backpressure, emitted-chunk, and RSS evidence through the same production adapter path without adding work to the scored route.

Results written before contract version 3 did not enforce the run-scoped dynamic challenge or require framework-owned Marko streaming. Contract-v3 stream results are also non-authoritative because they used a single measured sample and temporarily assigned four sequential deferred payloads only to Tachyon. Static throughput data can still be interpreted independently. New JSON results use the shared provenance envelope, include `benchmark.contractVersion: 4`, record a fresh-process run ID, seed, run index, actual framework order, raw stream samples, resolved workload controls, and framework build/start commands, and use timestamped or explicitly run-scoped filenames without overwriting older files.

An authoritative cross-run ranking requires at least five clean fresh-process runs with compatible provenance and balanced framework positions. Each process contributes one ratio observation; within-process stream samples are retained for recomputation but are not independent bootstrap observations. The older production smoke run at `results/2026-07-10-contract-v2-smoke.json` and all contract-v3 results remain preserved as legacy artifacts.
