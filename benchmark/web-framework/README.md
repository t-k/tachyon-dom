# Web framework benchmark contract

Contract version 5 makes the repeated stream distribution auditable from raw samples and a signed fresh-process artifact. Every run creates high-entropy product IDs that are unknown to the fixture and uses them for both validation and the measured dynamic URL. Each response must contain its requested ID and remain distinct, so a finite table of bodies prepared before the run cannot satisfy the contract.

The scored stream scenario has one 20ms deferred dependency, one 80-item payload, and one shell-to-done boundary for every framework. The runner records every downstream chunk arrival timestamp and rejects any sample unless the shell and `data-stream="done"` payload arrive in distinct chunks at least 10ms apart. Full runs use 5 warmups and 20 measured samples per framework. Tachyon's separate `/stream-evidence` route preserves multi-chunk completion, cancellation, backpressure, emitted-chunk, and RSS evidence through the same production adapter path without adding work to the scored route.

Results written before contract version 3 did not enforce the run-scoped dynamic challenge or require framework-owned Marko streaming. Contract-v3 stream results are non-authoritative because they used a single measured sample and temporarily assigned four sequential deferred payloads only to Tachyon. Contract-v4 results lack raw-summary and artifact-digest enforcement. Static throughput data can still be interpreted independently. New JSON results use the shared provenance envelope, include `benchmark.contractVersion: 5`, record a fresh-process run ID, seed, run index, actual framework order, raw stream samples, resolved workload controls, framework build/start commands, process identity, and canonical SHA-256. Filenames are timestamped or explicitly run-scoped and never overwrite older files.

An authoritative cross-run ranking requires at least seven clean fresh-process runs with compatible provenance and complete framework-position cycles. Because the current suite has six frameworks, the smallest accepted set is two complete cycles, or 12 runs. The validator regenerates every framework order from seed and run index and rejects altered or incomplete cycles. Raw `streamSamples[*].complete` values are the source of truth: the validator recomputes each median and rejects a contradictory `streamCompleteMs`. Each process contributes one raw-derived ratio observation; within-process samples are not independent bootstrap observations. Invalid manifests and duplicate process identities are rejected. Contract-v4 and older results remain legacy artifacts.
